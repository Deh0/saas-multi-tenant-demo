# Lógica do Sistema

Neste módulo **não** vamos aprender lógica de programação, vamos entender como conseguir criar a lógica de um sistema do zero. 
De acordo com os requisitos do sistema, diagramas e modelagem de dados. Conseguimos identificar a lógica por trás de tudo isso e fazer funcionar corretamente de acordo com o esperado. 

## O que seria a lógica do sistema?

A lógica do sistema é tudo aquilo que o usuário e sistema podem ou devem fazer. 

Exemplo:

O usuário acessa x página > sistema carrega x página em x segundos;

O Usuário realiza login > sistema valida credenciais; 

Esse exemplo acaba de nos dar quatro funções para o nosso projeto, essas quatros funções são a lógica do nosso sistema. 

De acordo com os [requisitos funcionais do módulo de login](../../requisitos/requisitos_funcionais/login.md), nosso sistema contém regras e processos. De acordo com os [diagramas de atividade](../../diagramas/atividade/login.md), nosso sistema contém fluxo e lógica. De acordo com a [modelagem de dados](../../modelagem/conceitual/login.md), nosso sistema contém entidades, relacionamentos, e atributos. 

Usuário deve possuir CPF e senha para acessar o sistema, então conseguimos entender disso que o sistema deve validar o CPF e a senha do usuário.
