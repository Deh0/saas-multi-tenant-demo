## Descrição textual

A descrição textual é a documentação narrativa de um sistema, descrevendo funcionalidades, requisitos, atributos e comportamentos. Serve para a criação da documentação do projeto, validar os requisitos, desenvolver uma base para a criação de diagramas e para uma boa comunicação entre clientes e desenvolvedores. 

Todas as entidades serão descritas com a primeira letra maiúscula e em negrito, os atributos normalmente serão identificados dentro de um parêntese ou de uma forma intuitiva, os relacionamentos serão abordados de uma maneira mais natural, como uma entidade fazendo referência a outra entidade. 

Vale ressaltar que na modelagem de dados não pode conter caracteres especiais, pontuação, espaços ou acentuação. Com isso, algumas entidades não estão escritas da maneira correta para facilitar o entendimento. Para saber os nomes corretos pode buscar pelo tópico [Entidades](#entidades), onde terá as informações corretas.

Nesta descrição vamos abordar somente os tópicos relacionados ao e-commerce, porém algumas entidades são compartilhadas entre o e-commerce e o ERP, pois representam informações utilizadas tanto na experiência de compra do cliente quanto na gestão interna da empresa contratante. Entre elas estão: Produto, Pedido, Pagamento, Estoque, etc.

> Lembrando que está descrição textual, e os requisitos do sistema não estão 100% fieis a realidade. Já que esse projeto se trata de uma versão reduzida, focada para descrever todos os processos do projeto real, com um intuito didático para ensinar aqueles que buscam aprendizado prático.
